# ASCII Studio application

This workspace contains the Next.js site, creative tools, ASCII editor, and showcase administration routes.

See the [repository README](../../README.md) for setup, commands, architecture, browser limitations, and optional administration configuration.

Run the documented install and build commands from the repository root. To launch this app directly with a custom development port:

```sh
node ../../scripts/dev.mjs --base 4000 --webpack
```
